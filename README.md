# The Sloth Slap™ Game

A comical cartoon slap-'em-up starring a crew of sloths.

## ▶ [Play it now in your browser](https://marknakasone85.github.io/sloth-slap-game/)

Free, nothing to install. It works on computers, phones and tablets.

*Sloth Slap™ is a trademark of Mark A. Nakasone. See [Trademark and copyright](#trademark-and-copyright).*

  Flying enemies (birds, bats, drones, UFOs) go down with one slap or one shot. When a boss runs into you it **bumps you back** out of its way (or over it, if you're against a wall) instead of pinning you, and **blocking works against bosses from any side**.

  **Guns & grenades:** every sloth starts with a pistol (6 bullets that slowly refill) and 3 grenades. **Grenades (G)** are lobbed in an arc and blast everything nearby; grenade pickups give +2 and you can carry up to 10. Glowing **"?" weapon boxes** (a couple per map, one right before each boss, and sometimes in crates) hold a random big gun with limited ammo: a **shotgun** (5 pellets per shot), a **rocket launcher** (exploding rockets) or a **belt-fed machine gun** (hold Shoot). When it runs dry you're back to the pistol. In Slapdown Duel each sloth gets 2 grenades per round, and every 10 seconds or so a "?" weapon box **parachutes in from the sky**: whoever touches it first gets the big gun (jump to snatch it out of the air). Guns reset each round.

  **Health & power-ups:** a heart (+50 HP) waits just past every gate and before each boss. Enemies sometimes drop leaf snacks (+10) or hearts. Each map has two glowing power-up bubbles, and crates sometimes hold one:
  🛡️ Bubble Shield (no damage), 👊 Super Slap (double damage), 🔫 Rapid Fire (unlimited ammo), ☕ Coffee (super speed): each lasts 12 seconds.
  🍌 Lucky Banana: an extra life. If you get snoozed you pop right back up.

  **Every map can be chosen any time.** Beaten maps get a ✓ and your best score.
  - Before playing: pick your sloth and the list of all maps appears (Wi-Fi lobby: ←/→, or click the map name / press M).
  - During a map: **Pause → Choose Another Map**. It's also on the "Nap achieved!" and "Snoozed out!" screens. In Wi-Fi games the host picks and everyone moves to the new map together.

- **Co-op campaign** (Campaign → choose how to play):
  - **2 Players (this computer):** P1 uses WASD + F/K/H/R/G and P2 uses the arrow keys + , . / ; '
  - **Wi-Fi co-op, 2 to 4 players** on different computers on the same Wi-Fi (see *Playing together on Wi-Fi* below).
  - Everyone shares one screen. If you get snoozed while a teammate is still up, you pop back in next to them after 5 seconds. Checkpoints are only needed if the whole team goes down. Enemies get tougher the more sloths there are.
- **Slapdown Duel**: a fighting mode, first to 2 round wins. The round-winning slap plays in **slow motion** with a dramatic zoom (bigger for the match winner, and for every boss knockout in the campaign).
  - **vs CPU** (Sleepy / Grumpy / Savage) or **2 Players** on one keyboard.
  - **Wi-Fi Battle, 2 to 4 sloths:** free-for-all, and the last sloth standing wins the round (if time runs out, the most health left wins). The host can add **CPU sloths** in the lobby (C = add, X = remove) to fill empty spots. Late arrivals jump in at the next round. After a match: **Rematch** or **Back to Lobby** (same join code, nobody has to rejoin).

## Play it

### Play online (computers, phones and tablets)
**https://marknakasone85.github.io/sloth-slap-game/**: open it in any web browser and play. There's nothing to install, and on phones the touch buttons appear. The campaign, Slapdown Duel vs CPU and 2 players on one keyboard all work online. Wi-Fi games for 2-4 players need the home version (see *Playing together on Wi-Fi*).

### Web browser from the game folder (any OS)
Double-click `index.html`. That's all: there are no dependencies, no build step, and every graphic and sound is generated in code.

The online version is this same folder served by GitHub Pages. Any static host works the same way (itch.io as an HTML5 game, Netlify), and Wi-Fi play switches itself off on public web addresses.

### Native macOS / Windows app
This needs [Node.js](https://nodejs.org) (LTS) installed once.

```bash
npm install          # first time only
npm start            # run as a desktop app
npm run dist:mac     # build dist/*.dmg   (run on a Mac)
npm run dist:win     # build dist/*.exe   (best run on Windows)
```

## Sharing

**Another Mac:** in Finder, right-click the `Sloth-Slap-Game` folder, choose **Share → AirDrop**, and pick the other Mac. Or copy the folder over with a USB stick. On the other Mac, double-click `index.html`.

**Your home network:** double-click **`share-on-network.command`**. A window opens with this computer's Wi-Fi address, like `http://<wifi-network-address>:8000`. Anyone on the same Wi-Fi can type that into their web browser to play. Keep the window open while people play; close it to stop sharing.
- Only the game files are shared, read-only. Hidden files, the backup history and settings are never served, and folders can't be browsed (see `tools/share_server.py`).
- Sharing stops by itself after 3 hours.
- Only use it on your own home Wi-Fi, not on public Wi-Fi.
- The first time, macOS may ask whether Python can accept incoming network connections. Click **Allow**, or nobody else can connect.

## Playing on phones and tablets

Phones and tablets play in the web browser. On the computer, double-click `share-on-network.command`, then on the phone (on the same Wi-Fi) open the address it shows, like `http://<wifi-network-address>:8000`. Phones can't open the `index.html` file directly. Or just open the online version: https://marknakasone85.github.io/sloth-slap-game/

- **Touch buttons** appear the first time you touch the screen, sized for thumbs and anchored to the screen corners (on wide phones they sit mostly in the black bars beside the game). Left: ◀ ▶ to move and BLOCK. Right: SLAP (big), JUMP, BIG, SHOOT and SUPER (glows when your special is ready). Pause is in the top-right corner. Use several fingers at once to run and slap together.
- Hold the phone **sideways**. If you hold it upright, the game waits and asks you to turn it.
- Menus work by tapping, and screens that use Esc have a **◀ Back** button.
- Works for the solo campaign, Slapdown Duel vs the CPU, and **joining a Wi-Fi co-op game from a phone**.
- Tip: on iPhone/iPad, *Share → Add to Home Screen* makes it open full-screen like an app.
- On a phone or tablet, Pause → **Touch buttons: ON/OFF** hides them for this visit only; they always come back next time.

## Playing together on Wi-Fi (2-4 players)

1. **Host** (the computer that runs the game): double-click `share-on-network.command`, then open **http://localhost:8000** in a browser on that same computer.
   - Co-op: **Campaign → Host Wi-Fi Game**. Battle: **Slapdown Duel → Host Wi-Fi Battle**.
   - Pick your sloth and the lobby shows a **4-digit join code**.
2. **Everyone else** (computers or phones): open the address shown in the host's sharing window (like `http://<wifi-network-address>:8000`), choose **Join Wi-Fi Game** or **Join Wi-Fi Battle**, type the code, pick a sloth and press **Enter** (or tap) when ready.
3. The host picks a map or stage with ←/→ (battles: C adds a CPU sloth) and presses **Enter** to start. Late arrivals can still join.

**If someone's connection drops** (Wi-Fi hiccup, phone screen locked, app switched), the game rejoins automatically with the same code and sloth; they drop back in next to the team (in battles, at the next round). Short drops (under 20 seconds) don't even kick anyone out. If the host's connection breaks or the sharing window is restarted, the host re-opens the game **with the same join code** and everyone rejoins by themselves. The join code and address are always shown in a bar at the top of the screen during Wi-Fi games.

How it works: the host's computer runs the real game. The others send their button presses and draw what the host sends back (about 30 updates a second, roughly 1.5 KB each). The host's game keeps running even if its window is hidden, covered or in a background tab.

Security: only the host's own computer can start a game, joining needs the code, a device that types too many wrong codes is locked out for a minute, every player gets a secret token, messages are small and never saved, other websites can't talk to it, and it's still home-network only and turns off by itself after 3 hours.

## Backups

The folder is a git repository, so every saved version of the game can be restored. Ask Claude to "save a backup" after changes, or to "go back to the version from before X". The versions are also kept on GitHub at https://github.com/marknakasone85/sloth-slap-game.

## Controls

| Action | Player 1 | Player 2 |
|---|---|---|
| Move | A / D | ← / → |
| Jump | W | ↑ |
| Block (hold) | S | ↓ |
| Slap | F | , |
| Big Slap | K | . |
| Special (when the meter is full) | H | / |
| Shoot (pistol: 6 bullets, refill slowly; crates drop ammo. Hold it with the machine gun) | R | ; |
| Grenade (up to 10) | G | ' |
| Pause | Esc / P | Esc / P |

In single-player you can also use the arrow keys, Space, and J / K / L / ; / '. In both the campaign and Slapdown Duel, a key-hint strip along the bottom shows each player's keys and lights up the move they're doing. You can switch it off in the pause menu, and **Pause → Controls** shows the full list. Enemies splatter in their own color (monkeys red, beetles green, crabs blue, drones oil) and make silly noises when they go down. **Pause → Blood: OFF** swaps the blood for confetti. Gamepads work too: X = slap, Y = big slap, B = special, RB = shoot, LT = grenade, A = jump, LB = block. On phones and tablets there's a GRENADE touch button with your grenade count. Menus also work with the mouse or touch.

### Adding content
- **New sloth**: add an entry to `js/data/characters.js` with colors, an accessory (`tophat`, `shades`, `crown`, `headband`, `bow`, `helmet`), stats, and one of the existing specials.
- **New map**: add an entry to `js/data/levels.js` with a theme (`jungle`, `beach`, `temple`, `volcano`), enemies, crates, pickups, gongs/gates, platforms, and an optional boss.

## Privacy

The game collects no personal information. It has no accounts, ads, analytics or tracking, and it never sends anything over the internet.
- Progress and best scores are saved only in your own web browser (local storage) and never leave your device.
- Wi-Fi games stay on your home network. Button presses and game updates go between the players' devices through the host computer, are kept in memory only, and are gone when sharing stops.
- The online version is hosted by GitHub Pages. Like any website host, GitHub sees ordinary visit information (such as IP addresses); see GitHub's privacy statement. The game itself adds nothing to that.

## Content

Cartoon slapstick: slaps, bonks, silly sound effects, cartoon guns and cartoon grenades (KA-BOOM clouds, no realistic violence). Defeated enemies splatter in cartoon colors. **Pause → Blood: OFF** turns the splats into confetti.

Real places (Italy, China, Washington DC, Egypt, New York City) appear only as cartoon backdrops. All characters, creatures and bosses are made up. The game is not affiliated with or endorsed by any city, country, government or company.
